**Design idea.** With angles restricted to 0/π the two CNOT chains act as a fixed GF(2)-affine permutation of the pixel-index bits: after both chains the measured qubits hold q0 = r2, q1 = r1, q2 = r0⊕r2, q3 = c2⊕r1 (r = row bits, c = column bits). I use the final layer to (i) flip q1 and q2 so that class bitstrings 0/1, 2/3, 4/5 correspond to rows 3, 2, 1 (the busy upper rows) and 8/9 to row 6 (the bottom bar region), and (ii) put a near-Hadamard ry on q3. That rotation interferes pixel column c with column c+4 inside the same row, so the even-class outcome measures (x_c + x_{c+4})² ("loop / two strokes in this row", e.g. 0, 8, bottom of 2/8) while the odd-class outcome measures the difference (single stroke, e.g. 1, 3, 9 right-hand strokes). The angle is π + 1.37 rather than π + π/2 so that a single stroke in the right half of rows 2/3/6 is biased toward the odd (difference) class rather than tying, which pushes digit 1 toward class 1 and 9 toward class 9, while two-sided rows still go almost entirely to the even (sum) class. All other angles are 0 so the amplitude-encoded image is otherwise untouched.
