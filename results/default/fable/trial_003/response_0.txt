**Design idea.** The clearest difference between a 3 and an 8 in these 8×8 images is the left side of the middle region: an 8 has a closed left stroke in rows 2–5 (columns 1–2), while a 3 is open there and those pixels are essentially black. I sum those pixels with a single qubit: consecutive `ry` rotations on one qubit commute, so the total rotation angle is an affine function of the pixel sum. The offset is set so that a dark left side (3) leaves the angle below π/2 (measuring mostly |0⟩), while a lit left side (8) pushes it above π/2 (mostly |1⟩). Weights are chosen so the maximum possible angle stays below 3π/2, avoiding wrap-around.
